🚀 CÓMO USAR EL SISTEMA

CONFIGURACIÓN INICIAL (una vez):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ajustar parámetros en config.py:
   ```python
   USAR_KNN = True          # Activar sistema KNN
   K_VECINOS = 50           # Número de vecinos (30-100)
   HORIZONTE_KNN = 4        # Velas hacia adelante (2-8)
   PESO_KNN = 0.6           # Peso KNN vs LSTM (0.0-1.0)
   ```

2. Descargar datos históricos:
   ```bash
   python extraer_datos.py
   ```

3. [OPCIONAL] Obtener noticias:
   ```bash
   python noticias/obtener_noticias.py
   python noticias/analizar_sentimiento.py
   python noticias/integrar_modelo.py
   ```

4. Entrenar modelo LSTM (si no está entrenado):
   ```bash
   python entrenar_modelo.py
   ```

5. Entrenar sistema KNN:
   ```bash
   python entrenar_knn.py
   ```

💡 VENTAJAS DEL SISTEMA KNN
═══════════════════════════════════════════════════════════════════

✅ EXPLICABILIDAD
   → Muestra exactamente qué patrones históricos usó
   → Permite verificar manualmente las situaciones similares
   → No es una "caja negra" como LSTM

✅ RAPIDEZ
   → Entrenamiento: 1-2 minutos (vs 15 min LSTM)
   → Predicción: Instantánea
   → No requiere GPU

✅ ADAPTABILIDAD
   → Se actualiza automáticamente con nuevos datos
   → No necesita re-entrenamiento completo
   → Detecta patrones emergentes

✅ ROBUSTEZ
   → Menos propenso a overfitting que LSTM
   → Funciona bien con datos limitados
   → Estable en mercados volátiles

✅ COMBINACIÓN LSTM + KNN
   → Mayor precisión por validación cruzada
   → Reducción de falsos positivos
   → Confianza aumenta cuando ambos coinciden
   → Mejor que usar solo uno

• K = 100 → Más estable, más general

HORIZONTE_KNN (2-8 velas):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• H = 2  → Corto plazo (H4: 8 horas)
• H = 4  → RECOMENDADO (H4: 16 horas)
• H = 8  → Largo plazo (H4: 32 horas)

PESO_KNN (0.0-1.0):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 0.4 → Confiar más en LSTM (40% KNN, 60% LSTM)
• 0.6 → RECOMENDADO (60% KNN, 40% LSTM)
• 1.0 → Solo KNN, ignorar LSTM
