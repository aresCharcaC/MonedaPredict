📈 ESTRATEGIAS DE TRADING
═══════════════════════════════════════════════════════════════════════════

1. CONFIRMACIÓN DE SEÑALES
   ────────────────────────
   Si modelo predice EUR ↑ Y oro ↑ → COMPRAR (confianza alta)
   Si modelo predice EUR ↑ Y oro ↓ → ESPERAR (confianza baja)

2. DIVERGENCIAS
   ────────────
   Correlación alta + divergencia → Posible reversión
   Ratio desviación > 2 → Reversión a la media

3. CAMBIOS DE RÉGIMEN
   ───────────────────
   Correlación pasa de 0.7 a 0.3 → Cambio de sentimiento
   Ajustar tamaño de posición

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ Error: No se pudieron descargar datos del oro
   → Verifica símbolo en tu broker (XAUUSD, GOLD, XAU/USD)
   → Algunos brokers usan nombres diferentes

⚠️ Advertencia: Sin datos de ORO
   → Re-entrena el modelo: python extraer_datos.py + entrenar_modelo.py

❌ Correlación muy baja (<0.3)
   → Normal en periodos de fortaleza del USD
   → Verifica timeframe (H4 y D1 mejor que M5-M15)

💬 NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════

• El sistema es RETROCOMPATIBLE:
  → Funciona con o sin datos de oro
  → No rompe modelos anteriores

• Los datos de oro mejoran la precisión típicamente en:
  → 5-15% en timeframes H4/D1
  → 3-8% en timeframes H1
  → Menor impacto en M5-M15 (mucho ruido)

• El ORO es especialmente útil para:
  → Detectar cambios de sentimiento
  → Crisis económicas
  → Decisiones de bancos centrales

• NO es útil en:
  → Anuncios específicos de EUR (ECB, datos económicos)
  → Trading de muy corto plazo (scalping)
  → Pares sin correlación con oro (USD/JPY)
