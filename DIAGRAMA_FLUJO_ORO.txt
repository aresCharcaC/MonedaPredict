VENTAJAS DE CADA FEATURE DE ORO
══════════════════════════════════════════════════════════════════════════

Feature              │ Qué mide                      │ Cómo ayuda
─────────────────────┼───────────────────────────────┼─────────────────────
close_oro            │ Precio del oro                │ Nivel absoluto
ratio_eur_oro        │ EUR/USD ÷ ORO                 │ Relación de precios
ratio_desviacion     │ Desviación del ratio          │ Sobre/subvaloración
divergencia_retornos │ Retorno EUR - Retorno ORO     │ Detecta divergencias
oro_tendencia        │ Dirección del oro             │ Contexto tendencial
ratio_volatilidad    │ Vol EUR ÷ Vol ORO             │ Riesgo relativo
correlacion          │ Correlación móvil             │ Fuerza de relación
correlacion_ma       │ Media de correlación          │ Suavizado
oro_momentum         │ Momentum oro (5 periodos)     │ Velocidad cambio
